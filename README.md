# RetailCore

RetailCore — приложение нового поколения для категорийных менеджеров и специалистов по управлению ассортиментом.

Система помогает автоматизировать ежедневные задачи:
- анализ товарных каталогов;
- поиск и сравнение товаров;
- сопоставление ассортимента разных брендов;
- выявление аналогичных продуктов;
- настройка параметров поиска под различные категории;
- подготовка данных для принятия закупочных решений.

RetailCore создан для того, чтобы сократить время на рутинный анализ и повысить эффективность работы с ассортиментом.
