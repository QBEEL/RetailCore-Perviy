# Первая версия

`excel_matcher.py` — исходное приложение на tkinter, сохранено для сверки.

Заменено версией в `app/`. Причины замены, кроме интерфейса:

- объём извлекался только из латинских единиц (`ml`, `g`), поэтому для
  кириллических «10мл» не определялся у 737 из 739 записей каталога;
- нечёткое совпадение подставляло первого подходящего кандидата без проверки
  объёма: 46 из 116 совпадений связывали строки с разным объёмом (например,
  «Духи 50 мл» получали артикул и цену варианта на 10 мл);
- фильтр таблицы не возвращал скрытые строки, так как `Treeview.exists()`
  остаётся истинным для откреплённых элементов;
- сообщение об ошибке падало с `NameError`: переменная `except` уничтожается
  до вызова лямбды;
- колонки задавались числовыми индексами, а название бренда было зашито в
  регулярное выражение.

Запуск не поддерживается: `python legacy/excel_matcher.py` требует tkinter и
устанавливает openpyxl самостоятельно.
